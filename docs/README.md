# Adding Data for RAG

1. Put scheme content files in this folder using .md or .txt format.
2. Keep one scheme per file or one section per heading for better retrieval.
3. Include official references in text when possible (source name, portal, date).
4. Open the app sidebar and click "Index / Rebuild RAG Data".

## Suggested file pattern

- scheme-name.md
- state-scheme-name.md

## Example structure

# PM-KISAN

## Eligibility
Landholding farmer families can apply subject to official state records.

## Benefits
Income support is released in installments as per government notifications.

## How to Apply
Apply through the official PM-KISAN portal or state agriculture office.

## Source
pib.gov.in / pmkisan.gov.in
